# get_next_line

## Description
The `get_next_line` project is part of the 42 curriculum and focuses on reading a file line by line in C.  
The goal is to implement a function that reads one line at a time from a file descriptor, handling any BUFFER_SIZE and preserving the remainder of the file for the next call.

---

## Instructions
Make sure you have the following project files:
- `get_next_line.c`
- `get_next_line_utils.c`
- `get_next_line.h`
- Optional: `main.c` `test.txt` for testing the project
### Compilation
To compile your project, you can create a test file (`main.c`) and use `gcc`:
```bash
gcc -Wall -Wextra -Werror get_next_line.c get_next_line_utils.c main.c -o gnl
```
### Execution
```bash
./gnl
```
